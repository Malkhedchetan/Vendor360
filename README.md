
# 📊 Vendor Performance Analysis

Vendor Performance Analysis is a data-driven project designed to evaluate supplier efficiency based on **purchase, sales, delivery, and freight** metrics.
This project identifies top-performing vendors and helps organizations make better procurement decisions using analytics and visual insights.

## 🚀 Features

* Vendor performance scoring
* Purchase vs. sales trend analysis
* Freight cost analysis
* Delay and delivery performance tracking
* Interactive dashboards (Power BI / Python)
* Clean data preprocessing
* Business insights for procurement teams

## 🧠 What This Project Solves

* Identifies best and worst performing vendors
* Helps reduce procurement costs
* Improves supplier selection and negotiation
* Enhances supply chain efficiency

## 🔍 Key Insights Generated

* Top 5 high-performing vendors
* Vendors with high freight cost
* Vendors causing delivery delays
* Vendors contributing highest revenue
* Month-wise performance trends

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* Power BI / Tableau (optional)

## ▶️ How to Use

1. Place your vendor dataset in the `data/` folder
2. Open and run `analysis.ipynb`
3. View insights and charts generated
4. Use the Power BI dashboard for interactive exploration
